# VKMuzPremium

Telegram Mini App с демонстрационной музыкальной лабораторией и оформлением подписки через Telegram Stars. Интерфейс и сообщения бота — на русском языке.

## Тарифы

- PRO — ⭐99 каждые 30 дней, автоматическое продление.
- PREMIUM — ⭐299 каждые 30 дней, автоматическое продление.

Музыкальная лаборатория работает как демонстрация в браузере. Списание Stars станет реальным только после развёртывания Cloudflare Worker и базы D1, настройки webhook бота и подключения Mini App. Платёж подтверждается только после получения от Telegram `successful_payment`.

## Настройка сервера

Следуйте [инструкции по Cloudflare Worker и D1](payments-worker/README.md). Сервер проверяет подпись Telegram `initData`, создаёт счета в валюте `XTR`, обрабатывает `pre_checkout_query`, включает подписку только после успешного платежа и хранит сведения в D1. Команды бота: `/cancel`, `/plan`, `/terms`, `/support`, `/paysupport`.

## Секреты

Файл `.env.example` — пустой шаблон. Локальный `.env` игнорируется Git и не публикуется. Для развёрнутого Worker добавьте `BOT_TOKEN` именно как Cloudflare Worker **Secret**. Не помещайте токен в код сайта или публичный GitHub.

Для проверки настоящих покупок сначала используйте официальный тестовый режим Telegram. Не проверяйте списание на рабочем боте, если не хотите потратить Stars.
